Privacy, semplice

  • Nessun tracking, nessun cookie di profilazione, nessuna pubblicità.
  • Sul dispositivo: preferiti, viaggi, recensioni e checklist restano nel tuo browser (localStorage). Cancellando i dati del sito spariscono.
  • Account backend (facoltativo): se crei un profilo, email + password (hash Argon2id, mai in chiaro) servono solo per sincronizzare i tuoi dati tra dispositivi. Puoi uscire in qualsiasi momento: il logout revoca la sessione.
  • Link esterni: mappe, siti delle strutture e WhatsApp aprono servizi terzi con le loro policy.
  • Contatti: segnalazioni pubbliche via GitHub Issues (non inviare dati sensibili).
